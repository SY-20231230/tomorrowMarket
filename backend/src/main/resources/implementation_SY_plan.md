# 내일장 백엔드 (F, G, H, I, J 영역) 초정밀 안전 개발 계획

사용자님의 지적사항을 수용하여, 약 37개의 API와 비즈니스 로직을 단 한 번의 실수도 없이 완벽하게 개발하기 위해 **작업 단위를 기존 6단계에서 11단계로 더욱 잘게 쪼개어** 초정밀 단위로 재구성했습니다. 

각 단계는 2~5개 내외의 연관된 API만을 집중적으로 구현하여 검증하는 흐름입니다.

## 1단계: Entity 및 Repository 1:1 완벽 매핑
- **작업**: F, G, H, I, J 관련 DB 테이블을 JPA Entity로 구성. 인덱스를 완벽히 타는 Repository 쿼리 메서드 선언.
- **포함**: `PREDICTIONS`, `PREDICTION_RUNS`, `PREDICTION_EVALUATIONS`, `PREDICTION_REQUESTS`, `PREDICTION_FAILURES`, `SEARCH_LOG`, `ACCESS_LOG`
- **목표**: 서버 기동 시 `ddl-auto: validate`를 통과하는 완벽한 기초 뼈대 구축.

## 2단계: 주가예측(F) - 정기 예측 조회 기능 (F-001 ~ F-003)
- **작업**: 가장 단순한 형태의 예측 결과 조회 DTO, Service, Controller 구현.
- **포함**: 특정 종목/산업군 최신 정기 예측, 특정 종목 예측 이력 페이징 조회.

## 3단계: 주가예측(F) - 재분석 비즈니스 로직 및 AI 연동 (F-004 ~ F-007)
- **작업**: FastAPI(`WebClient`) 연동 클래스 작성 및 복잡한 캐시 확인 로직 구현.
- **포함**: 재분석 요청(On-demand), 진행 상태 조회, 분석 결과 반환, 단기 캐시 로직.

## 4단계: 통계(J) - 기본 로그 집계 (J-001 ~ J-002)
- **작업**: 사용자 로그 및 검색 기록 집계 기능.
- **포함**: 기간별 사용자 접속 통계, 기간별 검색 로그 통계 및 인기 종목 제공.

## 5단계: 관리자(H) - 기초 및 사용자 관리 (H-001 ~ H-004)
- **작업**: `ROLE = ADMIN` 권한 체크 및 사용자 데이터 제어 기능.
- **포함**: 관리자 대시보드(통합 통계), 사용자 목록 조회 및 권한/상태(`ACTIVE`, `SUSPENDED`) 변경.

## 6단계: 관리자(H) - 운영 통제 기능 (H-005 ~ H-009)
- **작업**: 시스템 내부 상태 조회 로직.
- **포함**: 뉴스 수집 수동 실행/상태 조회, 모델 활성화/상태 조회, 시스템 로그 조회.

## 7단계: 배치관리(I) - 기초 조회 기능 (I-001 ~ I-002)
- **작업**: 복잡한 실행(Run) 데이터의 조회 API 구현.
- **포함**: 주/월간 예측 실행 목록(페이징) 및 특정 배치의 실행 상세 정보 조회.

## 8단계: 배치관리(I) - 수동 실행 코어 로직 (I-003 ~ I-006)
- **작업**: 대량의 종목(60개)에 대해 실제 수동 실행을 트리거하는 비즈니스 코어 구현.
- **포함**: 주간 단기예측/월간 장기예측 수동 실행, 종가 수집 및 예측 평가 수동 트리거 로직.

## 9단계: 배치관리(I) - 장애 복구 및 진행률 (I-007 ~ I-011)
- **작업**: 실패 건 추적 및 자동화 모니터링 기능.
- **포함**: 실패/누락 건 상세 조회, 실패 건 재실행(Retry) 및 전체 강제 재실행, 누락 점검, 실시간 진행률 조회.

## 10단계: 예측비교(G) - 기초 및 차트 데이터 (G-001 ~ G-003)
- **작업**: 평가된 오차율 데이터 및 차트 시계열 응답 구성.
- **포함**: 예측 비교 목록/상세 조회, 프론트엔드 차트 렌더링용 시계열 데이터 응답 구성.

## 11단계: 예측비교(G) - 세부 성능 통계 (G-004 ~ G-008)
- **작업**: 성능 데이터 다차원 집계.
- **포함**: 전체 예측 성능, 종목별/산업군별/예측기간별/모델버전별 오차율 및 방향 적중률 통계.

---

> [!TIP]
> 위와 같이 **11개 단계**로 분할하면, 매 단계마다 2~5개 정도의 API만 집중적으로 구현하게 됩니다. 이렇게 하면 코드 누락이나 설계 오류를 원천 차단하고 한 점 부끄러움 없이 **100% 안전하고 완벽하게** 코드를 작성해 나갈 수 있습니다.
